# AuctionPrices

Аддон для WoW Forever. После полного сканирования аукциона показывает в подсказке предмета цену продажи всего стака.

## Как пользоваться

1. Откройте аукцион и нажмите **Сканировать** внизу слева.
2. Пока сервер отдаёт список, на кнопке написано **Получение лотов...**. Затем идёт **Обработка лотов (N%)**.
3. Наведите курсор на предмет. В подсказке появится строка **Цена на аукционе:**.

Повторное сканирование доступно через 15 минут. Пока оно недоступно, кнопка неактивна, а в подсказке к ней указано, сколько осталось ждать.

Настройки открываются в списке аддонов. Там видны дата последнего сканирования, число записей в базе и кнопка **Очистить базу**.

## Установка

1. Скопируйте папку `AuctionPrices` в `Interface/AddOns` клиента WoW Forever.
2. В списке аддонов включите **AuctionPrices**.
3. Перезагрузите интерфейс командой `/reload` или перезайдите в игру.

Аддон загружается только в WoW Forever.
